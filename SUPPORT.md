# Support

## Where to ask

- Use the bug-report form for a reproducible mismatch or unexpected result.
- Use the feature-request form for a scoped proposal with a real maintenance use
  case and a false-positive analysis.
- Use [GitHub Security Advisories](https://github.com/satoissei/agents-doctor/security/advisories/new)
  for vulnerabilities or privacy concerns; do not disclose them in public issues.

This is a volunteer-maintained project. Response targets are described in the
[maintainer playbook](docs/maintainer-playbook.md), but they are not a support SLA.

## Before filing

1. Check the [configuration guide](docs/configuration.md) and current release notes.
2. Reduce the problem to a synthetic directory tree where possible.
3. Include `agents-doctor --version`, the command, expected result, and actual result.
4. Remove secrets, private repository names, customer data, and full instruction-file
   contents. See [PRIVACY.md](PRIVACY.md).
