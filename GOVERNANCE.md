# Governance

## Current stewardship

The current primary maintainer is [@satoissei](https://github.com/satoissei). The
project welcomes contributors and may add core maintainers as sustained contribution
and availability make that appropriate.

## How decisions are made

The maintainer prioritizes fidelity to the documented loader model, low false-positive
rates, user privacy, and a small dependable surface area. Changes that alter loader
behaviour, rule identifiers, output schemas, privacy boundaries, or release policy
require tests and documentation in the same pull request.

Routine fixes may be merged after CI passes. Larger changes are discussed in an issue
or pull request first, with a concrete use case, compatibility impact, and rollback
plan. The [Code of Conduct](CODE_OF_CONDUCT.md) applies to all project spaces.

## Continuity

Repository settings, release workflows, and maintainer instructions are documented
in version control. If the primary maintainer becomes unavailable, a trusted active
contributor may request transfer or co-maintainership through GitHub's documented
repository-transfer process. No personal contact details are required in this file.

## Transparency

Release notes record user-visible changes. Security reports are handled under
[SECURITY.md](SECURITY.md); reporter identity and private details are not disclosed
without consent.
